# CleanTextly Project Instructions

## Project Overview

CleanTextly is a modern browser-based text utility platform.

The goal is to build the fastest, cleanest and most useful collection of text tools.

## Tech Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- shadcn/ui
- Cloudflare Pages

## Coding Standards

- Write production-ready code.
- Keep components small and reusable.
- Use TypeScript strictly.
- Use semantic HTML.
- Prefer Server Components unless client state is required.
- Avoid unnecessary dependencies.
- Never modify unrelated files.

## Folder Structure

components/

## UI Style

- Minimal
- Modern
- Fast
- Accessible
- Mobile-first

## Rules

- Never generate placeholder code.
- Never generate TODO comments.
- Keep components modular.
- Explain every file before editing it.
